O cartão Azure OpenAI usa o símbolo do Azure; o cartão OpenAI identifica o SDK Python. As integrações opcionais estão indicadas no README.

Hugging Face identifica as bibliotecas Transformers e Sentence Transformers usadas com modelos locais. PyTorch pertence ao perfil opcional `ml`; MLflow registra os experimentos. Os ícones não indicam promoção do candidato treinado nem uso de inferência hospedada pela Hugging Face.

O cartão pgvector identifica a extensão do PostgreSQL usada pela [busca vetorial](../../backend/src/evidencedesk/retrieval/repository.py); a [migração](../../backend/migrations/versions/0001_foundation.sql) cria a extensão e a coluna de embeddings.
